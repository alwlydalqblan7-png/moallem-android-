# خطة دمج دفتر التحضير في معلّم — فحص ما قبل التعديل

## نطاق العمل
- المصدر: `alwlydalqblan7-png/daftar-altahdir`، فرع `main`.
- الوجهة: `alwlydalqblan7-png/moallem-android-`، فرع `feature/safe-preparation-integration`.
- عدم تعديل فرعي `main` أو بيانات المستخدم أو تغيير معرّف Android.
- لا تُجرى استعادة فعلية لبيانات المستخدم دون نسخة قابلة للتحقق وموافقته.

## حقائق مثبتة من الكود
1. دفتر التحضير يخزن المفاتيح العامة في `localStorage`، ويصدرها عبر `createBackupPayload` بمعرّف `daftar-altahdir`، إصدار 1.
2. قائمة مفاتيح النسخة العامة: `preparations` و`annualPlan` و`weeklySchedule` و`students` و`studentNotes` و`studentAnnualReviews` و`gradebookRecords` و`gradebookLimits` و`gradebookRules` و`books` و`appSettings`.
3. ملفات PDF الثنائية لدفتر التحضير في `IndexedDB`، قاعدة `daftar-altahdir-files`، متجر `pdfs`، ولا تُضمن في النسخة العامة أعلاه.
4. دفتر السبورة يخزن الصفحات تحت `daftar-alsaboura-pages-v1` وله ملف تصدير مستقل بمعرّف `daftar-alsaboura` وإصدار 2.
5. معلّم يستخدم `localStorage` و`IndexedDB` الخاص به، مع وظائف استيراد وتصدير مستقلة.
6. دفتر التحضير يعتمد Capacitor 8، ومعلّم Capacitor 7؛ لا تُنسخ الاعتمادات أو ملفات Android مباشرة.

- [ ] التحقق من إمكانية فتح نسخة دفتر التحضير العامة وفحص بنيتها، دون استيرادها إلى التطبيق الأساسي.

- [ ] التحقق من ملفات PDF الأصلية أو آلية تصديرها، وعددها وسلامة فتحها.
- [ ] توثيق مفاتيح تخزين معلّم الحالية والتعارضات المحتملة ومعرّفات السجلات.
- [ ] إعداد أداة تحويل مستقلة تحفظ البيانات الأصلية، وتكشف التعارضات، ولا تستبدل البيانات بصمت.
- [ ] إضافة اختبارات تحويل واستعادة ذهابًا وإيابًا ببيانات اصطناعية.
- [ ] تشغيل اختبارات المشروعين وبناء الويب وAPK تجريبي.
- [ ] اختبار التثبيت والتشغيل على جهاز قبل أي دمج إلى `main`.

## ترتيب نقل الميزات
1. التحضير: الحقول، التنسيق، الألوان اليدوية والتلقائية، الطباعة والتوقيع.
2. الجدول والخطة السنوية والمواد والصفوف، مع تجنب التكرار.
3. الكتب وملفات PDF، مع المحافظة على الربط بالتحضيرات.
4. إدارة الطلاب والعلامات، دون تغيير معرّفات الطلاب.
5. دفتر السبورة كميزة اختيارية فقط بعد التأكد من رغبة المستخدم.
6. تنظيم الشاشات والمكونات وإعدادات النسخ الاحتياطي.

## معايير قبول
- عدم ضياع أي تحضير أو كتاب أو سجل طالب.
- عدم تغيير بيانات دفتر التحضير الأصلي.
- تطابق أعداد السجلات قبل وبعد النقل، مع تقرير تفصيلي للتعارضات.
- القدرة على استعادة نسخة احتياطية وتجربة التطبيق دون الاتصال بالإنترنت.
- عدم دمج الفرع التجريبي في `main` دون موافقة صريحة.
