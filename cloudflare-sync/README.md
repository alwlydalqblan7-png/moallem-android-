# مزامنة معلّم بين الهاتف والكمبيوتر

الخدمة تحفظ نسخة مشفّرة من مفاتيح بيانات التطبيق التي تبدأ بـ `m2_`. يتم تشفيرها محليًا باستخدام AES-GCM قبل إرسالها؛ خادم المزامنة لا يتلقى النص الأصلي للعلامات أو قوائم الطلاب. يعمل التطبيق محليًا دون إنترنت، ثم يزامن تلقائيًا عند عودة الاتصال.

## النشر

يتطلب نشر هذا العامل إعداد أسرار GitHub `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` نفسها المستخدمة لعامل الذكاء الاصطناعي. يُنشر العامل `moallem-sync` بشكل منفصل عن `moallem-ai` ويستخدم Durable Objects للتخزين.

لا تُدمج هذه التغييرات في `main` قبل مراجعة إعداد النشر. أنشئ فرع/PR، ثم أدمجه بعد الموافقة؛ ينشر GitHub Actions العامل عند تغيّر `cloudflare-sync/**` على `main`.

## إعداد الحساب

أنشئ حسابًا بكلمة مرور من جهاز يحتوي بياناتك أولًا. سجّل الدخول بالحساب نفسه على الجهاز الآخر. ملفات PDF في مكتبة الكتب تبقى محلية ولا تُرفع.

كلمة المرور لا تُرسل كنص مخزن: يستخدمها العامل للتحقق PBKDF2، ويشتق منها التطبيق مفتاح التشفير. لا يمكن استعادة بيانات السحابة إذا فُقدت كلمة المرور. احتفظ بنسخة التطبيق الاحتياطية المعتادة.
